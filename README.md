# Sz(8) over Q: paper and certificate

This repository contains a paper realizing the Suzuki group Sz(8) regularly over Q, together with the exact data and the programs that certify it. The paper is `main.tex`; `main.pdf` is a compiled working draft. Author: Sebastian Biallas; the AI-assistance disclosure is the author footnote on the title page.

The main result is an explicit regular Sz(8) extension over Q(s), obtained from a degree-65 Sz(8):3 polynomial by a rational cubic base change. The specialization at s = 0, or t = -7/5, has group Sz(8) over Q.

## Build and read

```sh
make paper
```

Requires a TeX installation with `latexmk`, `pdflatex`, and BibTeX. The paper is split into `sections/*.tex` and uses `references.bib`. The input order in `main.tex` determines the reading order; numeric source-file prefixes are retained for compatibility with verification scripts. Sections 2–5 prove the main theorem, Section 6 proves the smaller-presentation corollary, Section 7 describes discovery, Section 8 documents reproducibility, and Appendix A prints the smaller s = 1 number-field polynomial.

## Exact inputs and quick checks

`data/f.json`, `data/g.json`, and `data/monodromy.json` are the compact public inputs. `certificate/results/f_poly.json` and `certificate/results/g_poly.json` are byte-identical copies read by the certificate programs.

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
make check
```

The quick check verifies the digests in `certificate/manifest.json`, the exact cubic pullback, the specialization factorizations at 11 and 31, and the group generated by the stored permutations. It does **not** repeat analytic continuation or prove that those permutations are the polynomial's monodromy.

A full rerun replaces the reports and may change serialization or timings. After adopting its outputs, rewrite the manifest with `make manifest` (or `python3 scripts/write_manifest.py --pack-discriminant` to also store the new discriminant pickle).

## Additional checks

```sh
make nodes
make review-check
make cubic
```

`make nodes` is an exact alternative to the interval node test. It interpolates the discriminant modulo 1000003, checks its full degree and squarefree node factor, and checks degree-one gcds over every factor field. Together with the characteristic-zero discriminant identity, this proves that each additional discriminant root has exactly one double root. It takes about 45 seconds and requires PARI/GP. The full-run driver uses the interval proof.

`make review-check` verifies every coefficient of the polynomial printed in Appendix A, its exact isomorphism with `F3(Y,4)`, the Frobenius patterns at 11 and 17, coefficient heights, the public F3/bridge coordinate identity, the local equation at infinity, real signatures, and the complex-conjugation identity for the stored permutations. It uses certified root enclosures but does not repeat path tracking. `make cubic` also checks the conductor-117 fibers and the reference deck transformation.

Reports are saved under `certificate/results/nodes_modp_check.json` and `certificate/results/review_evidence_check.json`. The modular check does not replace the characteristic-zero discriminant computation, and these checks are not a complete independent rerun of the generic certificate.

## Reduced presentations

- `data/F3_L3P0P4.json`: the 47-digit generator of `L(3P_0+P_4)`, bidegree (65,7), with its bridge relation to `f` in `data/F3_bridge_psi.json`.
- `data/G3_L3P0P4_pullback.json`: its cubic pullback, 52 digits, group Sz(8) over Q(s).
- `data/P_number_field.json`: a 68-digit monic defining polynomial of the s = 0 specialization field; the inverse isomorphism is in `data/P_number_field_verify.json` and `data/P_number_field_verify_B.json.gz`, and `data/F3_spec_field_check.json` records a root of `F3(Y, -6/5)` in that field.
- `data/P_s1_number_field.json`: the monic 43-digit polynomial defining the s = 1 field, printed in Appendix A; `make review-check` verifies it.

All heights are primitive integer heights of the coefficient vector.

```sh
make reduced
```

reruns, from the data files alone and without PARI/GP or GAP: the field isomorphism (`T(A) = 0 mod P`,
irreducibility), the 52-digit specialization `F3(Y, -6/5)` defining the same field, the exact pullback
identity for `G3`, the stated heights, and the bridge from `F3` to `f` in full (about 15 minutes on 6
workers; `--skip-bridges` for the instant checks). Digests recorded in the data files refer to the files as published here.

## Full verification

Install PARI/GP and GAP with the primitive-group library, then run:

```sh
python3 scripts/run_certificate.py --workers 4
```

The exact cubic discriminants and the field identifications in Section 4 can also be checked separately with `make cubic` (requires PARI/GP). This check is included in the full run.

`gp` and `gap` should be on PATH. Alternatively set `GAP_BIN` to an existing GAP executable. The recorded reports were produced with Python 3.11.9, python-flint 0.9.0, SymPy 1.11.1, PARI/GP 2.17.4, and GAP 4.15.1.

The default run recomputes the exact discriminant and its roots from `f`, then runs all remaining stages and the specialization proof. Allow tens of minutes and several GB of memory. To reuse the losslessly compressed discriminant artifact while still re-certifying all node boxes in the consumer, use:

```sh
python3 scripts/run_certificate.py --reuse-discriminant --workers 4
```

The discriminant pickle is stored as `certificate/results/discriminant.pkl.gz`. The restore helper checks both compressed and uncompressed digests before restoring it. Only load this trusted project artifact as a pickle.

## Scope

The repository contains the independent certificate for the polynomial theorem. The discovery computations (the triangle-group engine, the exact genus-six model, and the modular reconstruction engine) are not included; they are not needed to verify the main theorem. Section 7 describes them and gives the prime counts and controls for the relevant Riemann--Roch computations.

## arXiv submission bundle

Run `make arxiv-bundle` to create `dist/sz8-over-q-arxiv.tar.gz`. The archive contains the LaTeX source and every `.json` and `.json.gz` file from `data/` and `certificate/`, placed below arXiv's top-level `anc/` directory. The generated `anc/README.txt` identifies the repository and explains the preserved paths.
